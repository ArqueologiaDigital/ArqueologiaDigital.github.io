Infuse - Zeebo multiplatform emulator / Qualcomm BREW reimplementation development #2

Infuse is a Qualcomm BREW subsystem reimplementation and Zeebo high-level emulator written from scratch, based purely on clean reverse engineering attempts. Currently it is using dynarmic ARM JIT core and boots some Zeebo commercial games as well as BREW samples. Event handling as well as input is implemented, however HID devices are not responding properly in games, on which I'm currently working on. Sound is partially implemented, however no backend is available yet.

Infuse can be currently built for the x86_64 and aarch64 platforms, supporting macOS, GNU/Linux as well as Windows operating systems. It achieves more than full-speed Zeebo emulation on Macbook Pro 2020 M1 based notebook with non-optimized debug build. Additionally, it was written in a way that allows it to be built as a fully native application on supported 32-bit ARM devices, so it is possible to easily port it to the Nintendo 3DS with native execution without ARM emulation being used. Rendering interfaces are wrapped then translated to the native APIs using external renderers with multiple backends being possible such as Vulkan, due to that some glitches are still existing as Infuse OpenGL stack implementation is not finished yet. All BREW interfaces are reimplemented from scratch and are using internal API exposed by Infuse HAL that covers stuff such as but not limited to filesystem access, synchronization and pool memory allocation.
