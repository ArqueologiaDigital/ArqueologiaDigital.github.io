O Claude acabou de desvendar o bug. Era uma instrução cutomizada do instruction set (udf = user defined function). Que no caso dessa CPU a Matsushita implementou como um bit-search e o compilador usou na implementação de Huffman decoder, que faz parte do algoritmo de decodificar JPEG.
Felipe "Juca" Sanches
The JPEG decoder. With the display fixed, the splash showed *noise* instead of green — the software JPEG decoder was producing garbage. The cause was a single unimplemented CPU instruction: the MN10300/AM33 udf07 op (a bit-search, BSCH) used in the decoder's Huffman step. The CPU core was silently skipping it, desyncing the entire bit stream. Implementing it (bit position of the most-significant set bit) made the splash decode pixel-clean — verified against a reference decode of the same table-ROM JPEGs.
Felipe "Juca" Sanches
O mais doido foi que ele deduziu qual seria a função da instrução desconhecida. Pra fazer isso ele fez disasm do trecho problemático do código, percebeu qual era "a cara" do código, deduziu sua função, e concluiu qual seria a instrução exata necessária ali para que o assembly correspondesse a uma implementação válida de huffman decoding.
