Quando eu trabalhava no Iphan a gente tinha duas AlphaServer como servidores, ambos rodando Windows NT 4
Pablo Vasques Bravo-Villalba
Uma delas era provavelmente uma AlphaServer 1000 4/233 ou 4/266 (CPU Alpha 21064A). Posso estar lembrando errado mas a data parece bater. Lembro que a velocidade do clock era quebrada assim.
Pablo Vasques Bravo-Villalba
A outra era provavelmente uma AlphaServer 4000 5/400 (provavelmente, CPU Alpha 21164A). Era super estranho configurar ela usando o firmware. A gente montou o RAID usando uma interface super estranha, mas o software de monitoramento rodava no Windows NT mesmo. Foi interessante quando um dos HDs pifou e a gente observou em tempo real o software reconstituir o array no HD reserva. Como ele aceitava hot swap, foi possível trocar o HD bichado sem downtime
Pablo Vasques Bravo-Villalba
O engraçado disso é que os discos seguiam uma ordem sequencial no array. Como o HD reserva era o último da lista, e o que pifou era um dos "do meio", então o RAID ia sequencial, pulava o disco bichado, ia até o disco reserva, e voltava para o disco seguinte ao bichado. Quando colocamos o HD novo, o array continuou usando o antigo disco reserva. Isso não teve downtime, mas se quiséssemos deixar exatamente como estava antes precisava usar o firmware. Pra mim não tinha muita lógica mas era assim que funcionava

Altair BASIC on Magic 1 HomebrewCPU

Fifty years ago, Bill Gates, Paul Allen and Monte Davidoff wrote a BASIC interpreter for the Altair 8800 computer. This program launched Microsoft, and remains an excellent example of packing functionality into a tiny memory footprint.

I thought it would be fun to port this historic program to my Magic-1 HomebrewCPU computer. This video describes some of the tricks used by Altair BASIC and discusses the process of porting it to Magic-1.

Incidentally, you can try it out yourself by telnetting into Magic-1. Try:
telnet magic-1.org 51515
user: guest
password: magic

Only one telnet session at a time is allowed, so be patient. Also, to cleanly exit I modified the program to accept a "BYE" command to exit. Control-C acts as a BREAK key.

For more information on Magic-1, see: homebrewcpu.com

For background on the source code I used, see: altairbasic.org

For Bill Gate's release of the original source code, see: https://www.gatesnotes.com/microsoft-original-source-code
